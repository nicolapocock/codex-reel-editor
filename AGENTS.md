# Codex reel editor

For reel editing, read `skills/reel-editor/SKILL.md` and use its template engine. Run every script with a consistent `REELS_HOME`; prefer a writable `reels/` folder in this project. Treat raw media as originals and work from a copy. Local review uses `review_server.py`; never require Claude artifact tools. This repository is a local Codex port, not a deployed ChatGPT app. Do not upload footage unless the user requested a service that requires it.
