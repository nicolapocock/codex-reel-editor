## Defect fixed

Review jobs kept their rendered master and fonts inside isolated build folders. Consequently, the thumbnail studio did not discover the built footage or fonts after a successful review build. Successful builds now publish master.mp4, final.mp4 and cover font assets into the reel's accessible files. The thumbnail API resolves those font assets as a fallback. The previous versioned preview remains available.

Regression checks passed: cover handoff, review server/persistence/input validation, review import, actual template build/custom audio/missing audio failure, and six edit-policy tests.
