GETGITGIRL / LOCAL EDITOR

A clear first run.

This test build runs on your Mac. The review page stays on this computer. Keep the server terminal open while you review.

1. Open the project in Codex

Open the codex-reel-editor folder as your project. Copy this entire message into Codex:

Read AGENTS.md and skills/reel-editor/SKILL.md. Set up this reel editor using a reels folder inside this project as REELS_HOME. Check my tools, help me create my brand settings, and prepare a local review from my footage. Start review_server.py with --enable-builds and open the printed link for me.

2. Install the local renderer

Run this in a terminal inside the project folder. It uses the versions included with this test build.

npm ci

Node.js, Python 3 and ffmpeg are required. Codex can check what is missing before installing anything.

3. Check your video tools

bash skills/reel-editor/scripts/doctor.sh

If you already use Homebrew on your Mac and need the video tools:

brew install ffmpeg node

If brew is not installed, ask Codex to walk through the official Homebrew setup first. Wait for each command to finish before the next.

4. Review, then build

Your review link opens after the footage and transcript are prepared. Use Cuts to keep or remove words. Use Captions to correct spelling, choose accent words, and adjust size and position. Use Sound & colour to compare the voice tracks.

Open Preview and press Build preview. The editor saves your choices and renders locally. The status tells you what is happening. When ready, play or download the result.

Written instructions like “replace this graphic” still need Codex to interpret them. The editor will tell you when a note needs attention rather than silently ignoring it.

If something stops

No review page? Ask Codex to run prepare_review.py, then start review_server.py with --enable-builds and open the URL printed in the terminal.

Build failed? Your last successful preview stays available. Ask Codex to inspect review_build.log in the reel folder.

Unsaved changes? Keep the tab open and use Retry save. A warning appears if you try to leave before saving finishes.

Text over your face? Move the caption-position slider and check the rough preview before rebuilding.
